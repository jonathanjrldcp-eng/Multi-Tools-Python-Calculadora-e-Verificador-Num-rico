#Multi-Tools-Python-Calculadora-e-Verificador-Num-rico
Um utilitário de terminal interativo feito em Python, contendo um sistema de navegação em menu com duas ferramentas embutidas: uma calculadora básica (com suporte a verificação de divisão por zero) e um verificador de sinal numérico (Positivo, Negativo ou Zero).
##Funcionalidades

- **Menu Interativo:** Navegação fluida entre os aplicativos via terminal.
- **Calculadora:**
  - Realiza as 4 operações básicas (`+`, `-`, `*`, `/`).
  - Proteção contra erros de divisão por zero.
  - Otimizada usando dicionários com funções *lambda* para código mais limpo.
  - Verifica entradas inválidas (ex: letras ao invés de números).
- **Verificador Numérico:** Avalia instantaneamente se um número digitado é maior, menor ou igual a zero.
- **Limpeza de Tela Dinâmica:** Funciona perfeitamente tanto no Windows (cmd/powershell) quanto no Linux/Mac (bash/zsh).

##Pré-requisitos

Para rodar este script, você precisará ter instalado em sua máquina:
- Python 3.x
